Excel Analytics API v2

All routes except /health and /api/auth/* need Authorization: Bearer <token>.

MethodRoutePurpose
POST/api/auth/register · /loginCreate account / log in (returns token + user)
GET PATCH DELETE/api/users/meProfile, rename, delete account
POST/api/users/me/passwordChange password
POST GET/api/datasetsSave parsed dataset / list (search, sort, starred, page)
GET/api/datasets/statsDashboard totals + recent files
GET PATCH DELETE/api/datasets/:idMetadata, rename/star, delete
GET/api/datasets/:id/sheets/:indexRows of one sheet
GET/api/datasets/:id/download?format=xlsx|csvExport
PUT/api/datasets/:id/insightsCache AI insights
GET POST/api/ai/status · /insights · /askAI (key stays on the server)
GET PATCH DELETE/api/admin/*Admin only: stats, users, roles, files
